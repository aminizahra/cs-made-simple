# Underrated Algorithms

Lesser-known ideas that deserve more attention. Each one gets:

1. The idea in 3 steps.
2. The intuition behind it.
3. A small experiment with measured results.

## Planned

| ID | Algorithm | Experiment |
| --- | --- | --- |
| U01 | Bloom filter | Measured false-positive rate vs the formula, by bits per item |
| U02 | Reservoir sampling | Uniform sampling from a stream of unknown length |
| U03 | Aho-Corasick | Searching thousands of keywords in one pass |
| U04 | Isolation Forest | Anomalies get isolated in fewer random splits |
| U05 | HyperLogLog | Counting millions of unique items with a few kilobytes |

Each will live in its own folder: `u01-bloom-filter/`, `u02-reservoir-sampling/`, and so on.
